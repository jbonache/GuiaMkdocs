    2.1. Projecte únic

    📚 Guia d'estructura per a projectes MkDocs únic

    Un sol mkdocs.yml en l'arrel i totes les unitats com a subcarpetes dins de docs/.

    1️⃣ Estructura de carpetes

    mi-proyecto/
├── mkdocs.yml
├── docs/
│   ├── index.md                # Página principal (puede ser HTML incrustado)
│   ├── img/                    # Imágenes globales
│   ├── u1/
│   │   ├── index.md
│   │   └── otros-archivos.md
│   ├── u2/
│   │   ├── index.md
│   │   └── ...
│   └── ...

    2️⃣ Contingut bàsic de mkdocs.yml

    site_name: Portal MkDocs
site_url: https://usuario.github.io/mi-proyecto/
theme:
  name: material
nav:
  - Inicio: index.md
  - Unitat 1: u1/index.md
  - Unitat 2: u2/index.md
  # Añadir más unidades según sea necesario

plugins:
  - search
  # Otros plugins opcionales

extra_css:
  - css/estilos.css
extra_javascript:
  - js/funciones.js

    ✅ Avantatges:

    • Cada unitat és independent i pot tindre el seu propi tema/plugins.
    • Portal central que unifica l'accés.
    • Fàcil recompilar només una unitat sense tocar les altres.
