    2.2. Projecte compost

    📚 Projecte MkDocs pare + subprojectes compilats en subcarpetes

    En esta opció tens: - Un projecte pare que actua com a portal. - Subprojectes independents (u1, u2, …), cadascun amb el seu propi mkdocs.yml. - Cada subprojecte es compila i la seua carpeta site/ es col·loca dins del docs/ del projecte pare.

    1️⃣ Estructura de carpetes

    portal/                  # Proyecto padre
├── mkdocs.yml
├── docs/
│   ├── index.md          # Página central con enlaces a unidades
│   ├── img/              # Recursos globales
│   ├── u1/               # site compilado de unidad 1
│   ├── u2/               # site compilado de unidad 2
│   └── ...
u1/                      # Subproyecto 1
├── mkdocs.yml
├── docs/
│   ├── index.md
│   └── otros.md
u2/                      # Subproyecto 2
├── mkdocs.yml
├── docs/
│   ├── index.md
│   └── otros.md

    2️⃣ Flux de compilació

    # 1. Compilar cada subproyecto hacia el docs/ del portal
cd u1
mkdocs build -d ../portal/docs/u1

cd ../u2
mkdocs build -d ../portal/docs/u2

# 2. Compilar el portal
cd ../portal
mkdocs build

    3️⃣ Contingut bàsic del mkdocs.yml del portal

    site_name: Portal principal
site_url: https://usuario.github.io/portal/
theme:
  name: material
nav:
  - Inicio: index.md

plugins:
  - search

    4️⃣ Pàgina principal (portal/docs/index.md)

    <div class="landing-container">
  <div class="card">
    <a href="./u1/index.html">
      <div class="card-header">Unitat 1</div>
      <div class="card-body">Accedeix a: Unitat 1</div>
    </a>
  </div>
  <div class="card">
    <a href="./u2/index.html">
      <div class="card-header">Unitat 2</div>
      <div class="card-body">Accedeix a: Unitat 2</div>
    </a>
  </div>
</div>

    ✅ Avantatges:

    • Cada unitat és independent (pot tindre el seu propi tema i plugins).
    • Permet recompilar només una unitat sense tocar les altres.
    • Portal central amb navegació a totes.

    ⚠ Inconvenient:

    • Més passos manuals per compilar i sincronitzar subprojectes.
