    3. Desplegament en GitHub

    1️⃣ Crear el repositori públic en GitHub

    • Ves a https://github.com/new
    • Posa-li un nom (exemple: portal-mkdocs).
    • Marca Public.
    • No afegisques README ni .gitignore (pujarem el projecte des de local).

    ⚠️ Si no vols pujar els fonts al repositori, ves al pas 6️⃣, on només es desplegarà la carpeta /site al repositori.

    2️⃣ Preparar el teu projecte local

    Assegura’t que la teua estructura és així: 

    portal/
  mkdocs.yml
  docs/
    index.md
    u1/
    u2/
    ...
  site/              <-- generat amb mkdocs build

    💡 No cal pujar manualment la carpeta site/; mkdocs gh-deploy la genera i la puja automàticament.

    En el mkdocs.yml assegura’t de tindre el site_name i opcionalment site_url:

    site_name: Portal MkDocs

    site_url: https://TU-USUARIO.github.io/portal-mkdocs/

    3️⃣ Inicialitzar Git en local

    En la teu carpeta portal:

    cd /ruta/a/portal

    git init

    git branch -M main

    git remote add origin https://github.com/username/portal-mkdocs.git

    (Cambia "username" pel teu usuari real de GitHub.)

    4️⃣ Afegir i pujar els fonts

    git add .

    git commit -m "Versión inicial del portal MkDocs"

    git push -u origin main

    Ara el teu repositori ja té els fonts.

    5️⃣ Activar GitHub Pages

    Entra al teu repo en GitHub → Settings → Pages.

    En Source tria:

    • Deploy from a branch
    • Branch: gh-pages
    • Folder: / (root)

    Guarda.

    6️⃣ Instalar MkDocs y desplegar

    Si no el tens al teu entorn virtual:

    pip install mkdocs mkdocs-material

    (i qualsevol altre plugin que uses, per exemple: mkdocs-glightbox)

    Després desplega: 

    mkdocs gh-deploy

    Això:

    • Genera la carpeta site/.
    • Fa commit al branch gh-pages.
    • Puge a GitHub.

    7️⃣ Veure la teua pàgina

    Després d’1–2 minuts, GitHub Pages publicarà el teu lloc en: https://username.github.io/portal-mkdocs/

    8️⃣ Desplegaments futurs

    Cada vegada que canvies alguna cosa:

    git add .

    git commit -m "Actualización portal"

    git push

    mkdocs gh-deploy

    📌 Pots construir un script que automatitze el desplegament.

    #!/bin/bash
# Script de despliegue para el portal

# Detener ejecución si ocurre un error
set -e

# Entrar en el repositorio
cd PortalXX || { echo "No se encuentra el directorio PortalXX"; exit 1; }

# Traer cambios remotos primero (para evitar errores non-fast-forward)
# git pull --rebase origin main

# Construir el site completo
mkdocs build 

# Añadir cambios, si se quieren los fuentes en el repositorio, si no, comentar lols siguientes 3 comandos
git add .
git commit -m "Actualización portal" || echo "No hay cambios para commitear"

# Subir cambios, si se quieren los fuentes en el repositorio
git push

# Desplegar con MkDocs (suponiendo que mkdocs.yml está dentro de PortalEDD)
mkdocs gh-deploy
